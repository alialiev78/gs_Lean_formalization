# Verification of this release

Verification date: 6 October 2026.

The supported Lean 4.35.0-rc2 migration is complete. The original README,
licence and existing documentation are preserved; the pinned toolchain files
and the current publication guides describe the execution environment.

## Environment

- Lean: `leanprover/lean4:v4.35.0-rc2`.
- Lean compiler commit: `11acb17ec6b07a8f9e9173e6845197929540936b`.
- Mathlib: `065356127b1dc0016f66b7283ce0ce2c4055aa55`.
- The toolchain matches the pinned mathlib `lean-toolchain` exactly.
- Every Git dependency is pinned in the committed `lake-manifest.json`.

The supported build and audit used `python3 scripts/verify.py`. The build of
the statement/proof interface used `lake build +Challenge +Solution`.
Fresh exports were generated by this toolchain's `leanexport` from the built
modules for precisely the targets selected in `comparator.json`, the permitted
axioms and the kernel primitive declarations used by the bundled Comparator.

The comparison used the toolchain's unmodified `Lake.Check.compareAt` and
`Lake.Check.checkAxioms`, not a textual comparison of theorem signatures.
It checked every selected theorem and the recursively used definitions,
then the axiom dependencies of all selected proofs. The resulting export was
accepted by `leanchecker --silent --from-export`, `nanoda_bin` with the three
permitted axioms, and `con-ron`.

## Required final CI check

The complete `lake comparator` CLI builds, exports and checks inside
`bubblewrap`. The preparation container refuses creation of the nested Linux
namespaces that bubblewrap needs. Therefore **a successful sandboxed CLI run
is not claimed here**. The mathematical comparison and kernel checks above
were run separately, with no change to the comparison functions or kernels.

The supplied `.github/workflows/lean.yml` runs the full build, axiom audit,
statement/proof build and sandboxed `scripts/verify-comparator.sh` on Ubuntu
22.04. Before submitting a commit to Palomar, wait for its complete workflow
and specifically its **Verify Comparator** step to pass. Palomar will also run
its own trusted, pinned verification at the submitted commit. A local report
does not replace that registry check or its editorial review.

## Mathematical scope

All 370 supported O/U modules are included. The 36 experimental SU sources
remain explicitly excluded from the supported build and are not certified by
this report. Challenge contains 16 intentional theorem proof holes allowed
by the statement/proof protocol. Neither Solution nor the supported library
imports Challenge, and the checked proofs have no `sorryAx` dependency.

The 16 compared results are the precise statement of record, with hypotheses
visible in `Challenge.lean`. The complete library contains auxiliary and
additional results. The original paper correspondence and exclusions are in
`docs/PAPER_COVERAGE.md` and `docs/REMAINING_WORK.md`; this report does not
assert that every sentence or numerical claim in the paper is formalized.

The release contains no downloaded dependencies, compiled artifacts or
intermediate build logs. Verification scripts create diagnostics only below
the ignored `.lake/verification` directory. See `PALOMAR_RU.md` for publication
instructions.
